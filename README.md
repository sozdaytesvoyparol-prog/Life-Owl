# Life Owl

Трекер дисциплины для ПК (Windows) и телефона (Android) с общим аккаунтом и синхронизацией.

```
desktop/  — приложение для Windows (Electron)
mobile/   — мобильная версия (оборачивается в apk через Capacitor)
server/   — сервер аккаунтов и синхронизации (Node.js, без зависимостей)
.github/  — автоматическая сборка exe и apk
```

## 1. Запустить сервер (один раз)

Сервер хранит аккаунты и копию твоих данных, чтобы ПК и телефон видели одно и то же.
Нужен любой хостинг с Node.js 18+ и HTTPS (подойдёт бесплатный Render или Railway).

**Render:** New → Web Service → подключить этот репозиторий →
Root Directory: `server`, Build Command: пусто, Start Command: `node server.js`.
Для сохранности данных добавь Disk (путь `/data`) и переменную `DATA_DIR=/data`.
На бесплатном тарифе без диска данные на сервере могут сбрасываться — приложение
само восстановит аккаунт и данные из копии на устройстве при следующем входе.

Проверка: открой адрес сервера в браузере — должен показать `{"ok":true,...}`.

## 2. Прописать адрес сервера

Вариант А (рекомендуется): открыть `desktop/src/config.js` и вписать адрес:
`window.LIFEOWL_SERVER = 'https://твой-сервер.onrender.com';` — тогда он встроен в exe и apk.
Вариант Б: ничего не менять, а в приложении на экране входа нажать «☁ Синхронизация» и ввести адрес.

## 3. Собрать exe и apk

1. Создай репозиторий на GitHub и загрузи в него всё содержимое этой папки.
2. Вкладка **Actions** → «Сборка Life Owl» → **Run workflow** (сборка также идёт при каждом пуше).
3. Через 10–15 минут внизу страницы запуска, в **Artifacts**, скачай:
   - `LifeOwl-windows` — установщик `LifeOwl-…-nsis.exe` (с ярлыком на рабочем столе) и portable `.exe`;
   - `LifeOwl-android` — `LifeOwl.apk`.
4. apk поставь на телефон (разреши установку из неизвестных источников). Это отладочная
   подпись: для обычного использования подходит, для магазина приложений понадобится релизная.

## 4. Аккаунт и синхронизация

- Регистрация: на любом устройстве — имя и пароль. Аккаунт создаётся на сервере и на устройстве.
- Вход на втором устройстве: те же имя и пароль — данные подтянутся с сервера.
- Данные отправляются через несколько секунд после изменений и проверяются каждые 30 секунд
  и при возвращении в приложение. Статус виден в Настройки → «Синхронизация».
- Если на двух устройствах менялось одно и то же, объекты объединяются; при конфликте побеждает
  версия того устройства, которое синхронизируется. Удаления, сделанные на одном устройстве,
  могут вернуться с другого — это известное ограничение первой версии.
- Работает без интернета: всё сохраняется на устройстве и отправляется при появлении связи.

## Локальная разработка

```
cd server && node server.js          # сервер на http://localhost:3000
cd desktop && npm install && npm start
cd mobile && python build.py         # результат: mobile/www/index.html
```
